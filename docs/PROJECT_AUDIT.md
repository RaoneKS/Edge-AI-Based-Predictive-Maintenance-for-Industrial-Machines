# Project Audit – Edge‑AI Predictive Maintenance

**Repository:** `~/fpga-ai-accelerator` (branch `cnn-integration-audit-20261101`)

---

## 1. Current Project Architecture

- **Accelerator core** – 8×8 INT8 systolic array (`rtl/` modules).  Supports tiling, dual‑bank SRAM, AXI‑Stream I/O, and requantisation (`quantize_unit.sv`).
- **Application‑level datapath** – `quartus/de10_standard_hw/` and `quartus/de10_motor_vibration/` contain board‑specific top‑levels that map the generic accelerator to the DE10‑Standard (Cyclone V) and orchestrate the bearing‑vibration CNN.
- **ML pipeline** – Python scripts in `ml/` prepare the CWRU bearing‑vibration dataset, train a 1‑D CNN, quantise to INT8, and export weight / bias binaries (`ml/artifacts/`).
- **Verification framework** – Python golden‑model (`verification/scripts/golden_model.py`) and a collection of autogenerated test vectors (`verification/cnn_vectors/`).  Testbench `tb/` runs the full accelerator against these vectors.
- **Hardware‑software integration** – Sensor acquisition code (`arduino/` and `scripts/capture_vibration.py`) streams 256‑sample windows to the FPGA via a serial interface.
